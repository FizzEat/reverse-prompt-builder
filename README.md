# 17 层文生图提示词构建器 (Reverse Prompt Builder)

> 告别生图抽卡：把画面拆解成四大系统、17 个层级，右侧实时拼接工业级英文提示词。

### 🌐 在线体验地址

👉 **[点击直接在线使用 (GitHub Pages)](https://fizzeat.github.io/reverse-prompt-builder/)**

---

## ✨ 核心特性

- **逐层填写，实时拼接**：左侧 17 个输入框逐层推导，右侧实时自动组合成排版工整的英文 Prompt；
- **三档版本一键切换**：
  - **基础版（5 层）**：人物、服装、动作、场景、画风，满足日常快速出图；
  - **进阶版（8 层）**：引入身体力学、机位透视与双光源冷暖对冲；
  - **高级版（15 层）**：补齐面部一致性锚点、全身动力链、光影微观质感与负面防御；
- **一键复制**：右上角一键 Copy，直接粘贴至 GPT Image 2.5 或 Midjourney；
- **零依赖单文件**：纯原生 HTML + CSS + JS，双击直接运行，无需配置任何后端或 Node 环境。

## 🚀 本地运行

1. 下载仓库中的 [`index.html`](index.html)；
2. 双击直接在任何现代浏览器中打开即可。
